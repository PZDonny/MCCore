# **MCCore**

Another Minecraft Plugin library with essential commands and a simple minigame API
> Maven dependency at the bottom

**Plugin Dependencies**
- WorldEdit
- WorldGuard

**Maven Dependency**
```
<dependency>
  <groupId>com.github.PZDonny</groupId>
  <artifactId>mccore</artifactId>
  <version>VERSION</version>
  <scope>provided</scope>
</dependency>
```
