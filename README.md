# MCCore - Another Minecraft Plugin Library

- ### Essential Commands
- ### Minigame API
- ### MongoDB Utilities
- ### Utility Classes for -
  - **Entities**
  - **Items Creation/Meta Changes**
  - **Scoreboard Builders**
  - **BossBars**
  - **ActionBars**
  - **and more...**

## API
```xml
<repositories>
  <repository>
    <id>jitpack.io</id>
    <url>https://jitpack.io</url>
  </repository>
</repositories>

<dependency>
  <groupId>com.github.PZDonny.MCCore</groupId>
  <artifactId>api</artifactId>
  <version>VERSION</version>
</dependency>
```
