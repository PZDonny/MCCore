# **MCCore**

Sequestered Minecraft Server plugin library and MongoDB connector (when enabled in config).

**Plugin Dependencies**
- WorldEdit
- WorldGuard


**Maven Dependency**
```
<dependency>
  <groupId>MCCore</groupId>
  <artifactId>mccore</artifactId>
  <version>VERSION</version>
  <scope>provided</scope>
</dependency>
```
